欢迎！这里是 [团队/实验室] 的内部论文分享会仓库。我们定期阅读和讨论前沿论文，沉淀知识和想法。

## 🎯 目标和规则
- **频率**：[例如：每两周一次，周三下午 3 点]
- **时长**：[例如：40分钟分享 + 20分钟讨论]
- **语言**：[例如：中文分享，PPT可用英文]
- **分享人**：组内成员及合作学生轮流，鼓励自愿报名

## 🚀 快速开始（如何参与）
1. **提议论文**：在 [Issues](../../issues) 中新建议题，附上论文标题、链接和简短推荐理由。
2. **认领分享**：在 `schedule/` 下的排期表中登记，并更新 Issues 状态。
3. **提交材料**：分享前 1 天，将 PPT/笔记按命名规则放入 `slides/` 和 `papers/` 对应目录，并提交 Pull Request (PR)。
4. **讨论与总结**：分享后，鼓励在 `discussions/` 下补充讨论纪要，或在 Issues 下继续跟帖。

## 📂 目录结构说明
- `schedule/`：分享计划和时间表
- `papers/`：论文原文（PDF）或 arXiv 链接
- `slides/`：分享用 PPT 或 Markdown 笔记
- `summaries/`：（可选）每篇论文的文字总结
- `discussions/`：（可选）分享会问答和讨论记录
- `templates/`：PPT 和笔记模板，建议统一使用

## 📝 文件命名规则
所有文件请统一使用格式：`YYYY-MM-DD_论文简称_分享人姓名.扩展名`
> 例如：`2026-08-18_Transformer_张三.pdf`
